Re:Mind — iPhone向けWebアプリ

【内容】
- 朝・日中・夜のチェックリスト
- 4つの自己分析メモ
- 気分記録
- 過去の記録一覧
- 直近7日間の達成率・記録日数・連続日数
- 端末内保存（localStorage）
- テキスト形式で全記録を書き出し
- PWA対応・オフラインキャッシュ

【iPhoneで使う手順】
1. このフォルダの中身を、HTTPS対応の静的Webホスティングにアップロードします。
   例：GitHub Pages、Netlify など。
2. 公開されたHTTPS URLをiPhoneのSafariで開きます。
3. 共有ボタン →「ホーム画面に追加」を選びます。
4. 追加時に「Webアプリとして開く」が表示されたら有効にします。
5. ホーム画面のRe:Mindアイコンから起動できます。

※ローカルのHTMLファイルを開くだけでは、ホーム画面アプリ化やオフライン機能は正常に動作しません。HTTPSで公開する必要があります。
※記録は利用中の端末・ブラウザ内に保存されます。別端末との同期や自動バックアップはありません。SafariのWebサイトデータを消去すると記録も消える可能性があります。定期的に「記録をテキストで書き出す」を利用してください。
